# Standards 0.1.1 — branch-only fast CI

Reviewed 16 October 2026. Standards tag: `standards-v0.1.1`. This patch supersedes 0.1.0 for downstream selection and retains its [Node/SQLite/Windows scope, version matrix, upgrade and recovery contracts](0.1.0.md).

The 0.1.0 branch workflow passed on GitHub/Linux with Node 22.23.3, including all 35 unit tests and a normal build. Publishing its tag also triggered an unintended duplicate push workflow. That event had an all-zero previous commit, so the art-direction gate compared the entire neutral starter against an empty tree and failed. This was a tag-event workflow defect, not a runtime or screenshot regression.

Push CI now explicitly selects branches, so tags do not start duplicate build jobs. Pull-request and branch verification remain enabled with one Node 22.23.3 job and no browser tests, matrix, screenshot artifacts, hooks or production/deployment visual dependency. Initial/new-site art-direction applicability remains its existing contract; this patch does not bypass that gate for branch/PR changes.

No application source, dependencies, schema, media or renderer inputs changed. All 0.1.0 clean-install/runtime/editor/native-media and local Windows visual/HUD/sensitivity receipts remain valid; the manifest records the certified source tree and evidence. The outer gallery `_key` limitation, optional multilingual/cache/admin/provider scopes and unverified Workers/D1/R2 Phase 5 profile remain unchanged. This is a private standards patch, not the Issue #11 community release.
