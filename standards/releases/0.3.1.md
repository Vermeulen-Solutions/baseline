## Changes for sites

2 change notes; the largest is a patch change. Each entry says which platforms it affects and how a site takes it.

### Copy into the site

#### Bounded sync ignores line endings when it compares local files

_static · tooling · Copy the named files into the site · files: `scripts/sync-baseline.mjs`_

`sync:baseline` hashed local files byte for byte against upstream's LF hashes. On Windows, Git with `core.autocrlf=true` rewrites a managed file to CRLF the next time it touches it, and the next sync reported that unchanged file as a local conflict. A local file now matches its recorded or incoming hash in either line-ending form, so this works whether the receipt was written from LF or CRLF bytes.

##### For sites

Copy `scripts/sync-baseline.mjs` whole before the next `sync:baseline`. A file that was reported as a conflict only because of line endings then applies normally.

### Arrives with the site's sync

#### Skills link to Baseline's docs by URL instead of paths sites do not have

_EmDash and static · skills · Arrives with the site's skill or source sync_

Baseline-owned skills linked to `docs/` and `audit/` files and to the optional design-surface skills with relative paths. Sites receive only the skills, so in an EmDash site those links led nowhere (27 dead links in one site). A shared skill also linked to an EmDash-only skill that static sites never receive. The 30 links now point to the file on Baseline's repository, with the local path beside them for a Baseline checkout, and a test keeps new skill links inside what every site installs.

##### For sites

Run the site's skill sync (`sync:site-skills`; static sites `sync:baseline`). Files a site copied in by hand to satisfy these links can stay.
