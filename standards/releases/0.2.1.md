# Standards 0.2.1 — Playwright 1.65.1 and Chromium 159 for local visual checks

Reviewed 16 November 2026. Standards tag: `standards-v0.2.1`. This patch supersedes 0.2.0 for downstream selection and keeps its [scope, framework versions and Node range](0.2.0.md): Astro 7.4.12, EmDash 1.5.0, Node `^22.23.4 || ^24.22.1 || >=26.12.1`.

## What changed

The local Windows visual renderer moves from Playwright 1.64.1 with Chromium revision 1248 (Chromium 156) to Playwright 1.65.1 with revision 1255 (Chromium 159). All 57 Windows reference images were renewed and reviewed: every difference is glyph and border anti-aliasing, no image changed size and nothing moved. Evidence: [audit/visual-renderer-2026-11-16/README.md](../../audit/visual-renderer-2026-11-16/README.md).

No application source, runtime dependency, schema, media or build output changed. The 0.2.0 clean-checkout, editor, restore and integration receipts remain valid.

## Changes for sites

- **Visual suites.** A site that runs Baseline's local visual suite needs `@playwright/test` 1.65.1, `npx playwright install chromium`, and new reference images reviewed the same way (`npm run test:visual -- --update`, then compare before accepting). Sites without the visual suite are unaffected.
- **`audit:ui` and captures** run on whichever Playwright the site has installed; 1.65.1 is recommended for parity with these references.
- **`audit:site`** compares against 0.2.1. Its dependency comparison is the same as 0.2.0, so a site that passed 0.2.0 passes 0.2.1. Reports produced against 0.1.1 and 0.2.0 still validate.

## Deferred

TypeScript 7 stays deferred until `@astrojs/check` and `@typescript-eslint/parser` accept it ([plan](../../docs/plans/playwright-1.65-and-typescript-7.md)).

## Known gaps

Unchanged from 0.2.0.

## Selecting this release

Resolve the immutable tag `standards-v0.2.1` to its full commit and read `standards/baselines/0.2.1.json` at that commit. Its SHA-256 must equal the `sha256` pinned in `STANDARD` in `scripts/audit-site.mjs`. Reject drafts, mutable `main`, changed refs and unsupported profiles.
