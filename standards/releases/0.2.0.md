# Standards 0.2.0 — current framework patches on the October 2026 Node security floor

Reviewed 16 November 2026. Standards tag: `standards-v0.2.0`. This release supersedes 0.1.1 for downstream selection. Scope is unchanged: Node/SQLite/local storage with the pinned Windows Chromium, on the representative starter CMS contracts. Evidence: [audit/certification-2026-11-16/README.md](../../audit/certification-2026-11-16/README.md).

The Node floor follows Astro: 7.4.2 requires Node 22.23.4, the October 2026 security release. The other lines use the same release (24.22.1, 26.12.1). Use the latest security patch of a supported line; the floor is not a recommendation.

## Changes for sites

- **Update Node first.** A site on Node below the new floor fails `npm run doctor` and is outside the certified range. Node 24 LTS is recommended.
- **`audit:site` compares against 0.2.0.** The temporary acceptance of a newer reviewed EmDash and of a second Node range is gone. A site still on Astro 7.4.0 or EmDash 1.3.0 now gets a `dependency:*` warning, which is the intended signal to update through the reviewed path in `docs/baseline-updates.md`. Reports produced against 0.1.1 still validate.
- **Checks.** The retired developer HUD check is gone. `audit:html` (required, against a fresh build) and `audit:ui` (advisory, local Chromium) are listed. The unit check runs through `npm test` and its tiers.
- **Restore runbook.** Remove `data.db-wal` and `data.db-shm` before copying a backup over a database; the drill for this release showed that leftover sidecars corrupt the restore.

## Deferred

`@playwright/test` 1.65 (new pinned Chromium, so the reference images need review) and TypeScript 7 (a major version that `@astrojs/check` and `@typescript-eslint/parser` do not support yet) are planned in [docs/plans/playwright-1.65-and-typescript-7.md](../../docs/plans/playwright-1.65-and-typescript-7.md). `@types/node` 26 and `parse5` 8 are majors and stay on the latest release of their current major.

## Known gaps

Unchanged from 0.1.1: the Workers/D1/R2 profile is unverified (Phase 5); live notification providers, opt-in multilingual, cache, admin and plugin block matrices are not certified; the gallery outer `_key` limitation remains. The restore drill did not attempt admin sign-in.

## Selecting this release

Resolve the immutable tag `standards-v0.2.0` to its full commit and read `standards/baselines/0.2.0.json` at that commit. Its SHA-256 must equal the `sha256` pinned in `STANDARD` in `scripts/audit-site.mjs`. Reject drafts, mutable `main`, changed refs and unsupported profiles.
