# Release guide explains runtime versions between releases

`docs/standards-releases.md` gains a section on how runtime versions move between releases and what a release does with them. Docs that named a fixed standards version or Astro patch (certification procedure, working rules, EmDash 1.6 guide) now point to `standards/manifest.json`, and the contribution and meta-review guides mention `packages:` and Renovate. Documentation only; sites have nothing to do.
