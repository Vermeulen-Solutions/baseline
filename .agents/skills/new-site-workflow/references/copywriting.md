# Copywriting and copyediting

Start here when the task is writing, rewriting or editing site copy: a homepage, service pages, calls to action, form wording or translations. This reference routes to the guidance that already exists; it adds no stage, template or approval stop.

## Route by task

| Task | Read | What it gives you |
| --- | --- | --- |
| Before writing anything | [discovery-and-content.md](discovery-and-content.md) → Interview prompts, Synthesize before designing | Audience, offer, next action, voice and **who speaks** (first person, studio name, visitor address), facts and restrictions |
| Planning a page's copy | [discovery-and-content.md](discovery-and-content.md) → Plan important pages before composition | Page brief: visitor, purpose, lead message, question coverage, section argument, draft copy at real length |
| Claims and proof | [discovery-and-content.md](discovery-and-content.md) → Claims, evidence and missing proof | The claim → source → permitted use ledger; no invented testimonials, metrics or promises |
| Headlines, section order, conversion copy | `astro-site-design/references/landing-page-archetypes.md` → Conversion copywriting engine | Outcome-led headline patterns and section pacing for marketing pages |
| Buttons, labels, form wording, errors, empty states | `impeccable/reference/clarify.md` | Interface microcopy: clear, specific, consistent |
| Several languages | `docs/internationalization.md` and the site's locale rules | One record per locale; translate meaning and register, not words |

## Working rules

- Write in each **site locale** for the page, and show the **owner's working language** version beside it when the owner approves copy (record both in discovery; they can differ).
- Draft at real length so layout is tested against real text, and keep editable copy in its content home (CMS fields or content files), not hard-coded in components, unless the brief decides otherwise.
- Keep copy consistent with the voice decision: a solo practitioner never implies a team; first person and visitor address stay the same across pages and languages (for example French *vous* throughout, with typographic spaces before `:`, `;`, `?` and `!`).
- Edit for the visitor's question first: what is this, is it for me, can I trust it, what happens next. Cut generic agency language that any studio could use.
- Record approved wording and its source in the existing brief or page notes; a saved draft is not approval.
