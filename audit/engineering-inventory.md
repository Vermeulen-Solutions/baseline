# Engineering inventory audit

Reviewed 2026-10-19: 58 original root scripts and 34 original top-level tests; final inventory has 60 scripts and 35 tests. Two runner modules and one infrastructure contract test were added. Cross-reference sources: package commands, both GitHub workflows, AGENTS.md, live imports/workers, profile manifests, checked-in skills and documentation. Historical audit receipts were inspected as context, not treated as proof of active use.

## Pruning decisions

No script or test file was deleted. Every original file has an active command, import, test-discovery or documented manual-maintenance path. The inventory review established no safe deletion candidate. Avoid deleting safety refusal stubs or integration coverage solely because a newer workflow exists.

| Candidate | Evidence and decision |
| --- | --- |
| `organize-media.mjs` | Retain: `media:organize` is a compatibility refusal command; media-infrastructure tests assert exit 2 and no database creation. Its dangerous raw-SQL implementation was already retired before this initiative. |
| `check-ci-fast.mjs` | Retain and wire into package/CI: budget receipt utility was previously a manually invoked inventory entry; it now enforces the budget and publishes evidence. |
| `rehearse-infrastructure.mjs` | Retain: documented manual database/media/R2 rehearsal in docs/image-delivery.md, with explicit local-only safety guard. |
| `pilot-migration.mjs`, migration-pilot test | Retain: documented lifecycle receipt, exercised from npm test. Separate importer tests cover detailed direct oracles, privacy and cleanup; pilot covers composition with cutover/recovery. |
| profile contract / delivery / boundary tests | Retain: manifest/provenance validation, generated Sveltia forms, and an actual independent Astro build cover distinct boundaries. Current platform-profiles.test.mjs contains no builds; the submitted estimate of 30s does not describe its current body. |
| historical schema fixture | Added for compatibility: exact pre-diagnostics helper bytes test legacy plan/apply/rollback. This is an intentional oracle, not an executable production script. |

Pruned implementation dead weight: seven Node subprocesses used only to read source files, two duplicate CLI argument loops, registry argument lookup/atomic-JSON writer, importer JSON reader, and unused imports (sources, fs, os, hashPrefixedToken). Assertions and supported package commands remain.

## Shared-helper boundaries

Use infrastructure-io argumentsOf/jsonOf/bytesOf/atomicJSON/isMain in compatible root operational CLIs. Keep audit-evidence readers separate because they return redacted unverified evidence instead of throwing; keep skill-sync optional async JSON and bounded baseline-sync path ownership separate. Shared static-profile scripts deliberately do not import infrastructure-io: its jsonc-parser/smol-toml dependency closure is outside their installed inventory. Keep subprocess cancellation and server lifecycle code local where its cleanup contract differs. Existing exit-2 unverified/privacy protocols remain; ordinary operational failures set exitCode 1 and let cleanup complete.
