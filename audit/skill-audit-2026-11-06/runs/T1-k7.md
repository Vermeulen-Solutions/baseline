After visual implementation (Express Checkpoint C / Stage 6, static):
1. `npm run design:tokens` and `npm run test:design` during edits (and `npm run dev` for live HTML/HMR).
2. `npm run verify` (installed profile suite: lint, CSS/art-direction/token checks, tests, typecheck as the generated site defines it).
3. `npm run build`.
4. `npm run check:dev-tools` (confirms `/_styleguide` and fixture markers are absent from the static build; fixture output is never deployable).
5. Manual/browser acceptance (recorded as such): routes at 375/768/1440, keyboard focus, responsive images, 404 behaviour (static host must return real 404, no SPA rewrite), `lang="fr"`, metadata/canonical (set `SITE_URL` if known), per `astro-site-design/references/rollout-verification.md`.
6. Not applicable on this profile and reported as such: `npm run doctor`, `verify:fast`, `audit:html`, `site:register`, EmDash registry/database/backup commands, Windows screenshot regression (`test:visual`), Sveltia login/upload checks.
