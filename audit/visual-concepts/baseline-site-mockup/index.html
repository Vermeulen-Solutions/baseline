Content setup

One foundation.
Three ways to edit.

The design tokens, components and checks are identical across profiles. What changes is where the words live and who can change them.

01 · static

Typed Markdown

Content stays in the repository as files your assistant can read and diff. Deploy is a folder of HTML.

02 · static-sveltia

Markdown, edited visually

Sveltia edits the same Git-owned files through a web form. No database, no content drift.

03 · emdash

Relational CMS

Portable Text, live canvas and MCP tools on SQLite or Cloudflare D1 and R2. Editorial content is never a seed.

The system

What is already decided for you.

Not a theme. A small set of contracts — surfaces, one accent, a type scale, a spacing hierarchy — plus the checks that keep them true as the site grows.

Roles, not moods

Page, surface and elevated are distinct roles. Text, muted and border are derived. One action colour carries every button, link and focus ring.

How it is built

Brief first.
Then a route.

Every stage leaves something the next one can check. Nothing visual ships before the direction is recorded.

01

Brief, evidence, platform

Real copy, real photography, the owner's own references. The platform profile is chosen here, not after the layout.

02

Art direction and tokens

A complete record — lane, metaphor, type pairing, token physics, anti-patterns — then primitives calibrated on the style guide.

03

One representative route

Build the hardest page, compare it with the selected direction, fix reflow and focus states, then roll the rest out.

what that buys

Tokens stay one source of truth. CSS keeps its layer order. Art direction cannot be skipped silently. Emitted HTML is checked for real, including server-rendered routes.

Scope

What it will not do.

Invent your art direction
Neutral tokens are a starting point. A lane, a metaphor and three anti-patterns are yours to choose and record.
Pretend a build is acceptance
Emitted HTML is not a browser. Client scripts, reflow and focus states are checked on a rendered page.
Hide the CMS boundary
EmDash records live in SQLite or D1, not in Markdown. Seeds are not migrations, and code deploys do not move them.
Recorded anti-patterns
  • Placeholder art direction: a lane and a type pairing are decisions, not defaults.
  • Invented proof: no fake logos, metrics or testimonials to fill a section.
  • Repeated skeletons: three cards saying the same thing in the same shape.
